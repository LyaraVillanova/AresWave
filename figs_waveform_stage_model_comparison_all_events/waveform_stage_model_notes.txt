- The panel CC values are visualization-stage diagnostics, not the official inversion misfit.
- Each panel is aligned independently using the best sign (+/-) and best lag.
- Therefore, this file is best used to discuss how waveform agreement evolves
  across preprocessing stages and across model choices.
